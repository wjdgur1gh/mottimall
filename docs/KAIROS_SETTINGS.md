## 2. 차트 설정

### 2.1 일봉 (스윙)

| 지표 | 설정값 | 용도 |
|---|---|---|
| 이동평균(종가, 단순) | **5 / 10 / 20 / 60** (+120 참고선) | 추세: 종가 > MA20 > MA60 / 지지: MA5, MA10, MA20 |
| 거래량 + 거래량 이동평균 | **20** | 눌림 구간 거래량이 20일 평균·임펄스 구간보다 줄었는지 |
| ATR | **14** | 사다리 간격(atr 모드)·변동성 확인 |
| 피보나치 되돌림 (수동 도구) | 임펄스 저점→고점에 긋기, **23.6 / 38.2 / 50 / 61.8** 표시 | 눌림 저점이 23.6~61.8 안에 있는지 |
| 가격 표시선 | 직전 임펄스 고점(1차 목표 후보), 눌림 저점 −1% (손절) | 주문표 값과 대조 |

### 2.2 3분봉 (데이트레이딩)

| 지표 | 설정값 | 용도 |
|---|---|---|
| 이동평균(종가, 단순) | **5 / 20** | 지지 |
| VWAP (매매가중평균가) | **당일 누적** — 지표 목록에 없으면 수식지표 `누적(거래대금)/누적(거래량)` 로 추가 | 종가가 VWAP 위일 때만 매수 |
| 거래량 + 거래량 이동평균 | **20** | 조정 중 거래량 수축 확인 |
| 전일 종가선 / 당일 시가선 / 당일 고가·저가선 | 표시 | 갭(≤15%)·임펄스(저점→고점 ≥3%) 판단 |
| 시간 구분선 | **09:10 / 14:30 / 15:15** | 진입 시작 / 신규진입 마감 / 강제청산 |
| VI 표시 | 정적 VI(기준가 ±10%)·동적 VI 발동 표시 켜기 | 발동 직후 추격 금지 |

## 3. [0544] 종합종목검색 — 스윙 눌림목 후보 (장 마감 후 검색)

조건식 이름: `눌림목_스윙`. A~L 을 **AND** 로 결합. 괄호 안은 프로그램 설정 키.

| 조건 | 분류(예상) | 항목 | 설정값 |
|---|---|---|---|
| A | 범위지정 | 시가총액 | **1,000억 이상** (`universe.min_market_cap`) |
| B | 범위지정 | 20일 평균 거래대금 | **50억 이상** (`universe.min_avg_turnover`) |
| C | 범위지정 | 현재가(종가) | **1,000원 이상** (`universe.min_price`) |
| D | 범위지정 | 상장일 | **상장 60거래일 이상 경과** |
| E | 범위지정 / 종목구분 | 제외 | **관리종목·투자주의/경고/위험·거래정지·정리매매 제외**, 스팩·우선주·ETF/ETN·리츠 제외 (보통주만) |
| F | 기술적분석 | 이동평균 배열 | **종가 > MA20 AND MA20 > MA60** (단순, 종가) |
| G | 시세분석 | 신고가 대비 | **30일 최고가 대비 −3% ~ −20%** (눌림 깊이) |
| H | 시세분석 | 신고가 경과일 | **30일 최고가 발생 후 2~12일 경과** |
| I | 시세분석 | 기간 등락률 | **42일 내 저점→고점 상승률 ≥ 10%** (항목이 없으면 '25일 전 대비 등락률 ≥ 10%' 로 대체) |
| J | 거래량 | 거래량 비율 | **최근 4일 평균 거래량 < 이전 10일 평균 거래량 × 0.85** |
| K | 기술적분석 | 이격도/지지 | **종가 ≥ MA20** AND 최근 12일 최저가 ≥ MA20 × (1 − 2%) |
| L | 패턴분석 / 시세분석 | 반등 확인봉 | **당일 양봉** AND **종가 > 전일 고가** AND **거래량 ≥ 전일 거래량 × 1.2** |

- 검색 결과를 **관심종목 그룹 `스윙후보`** 로 저장 → `pullback scan --mode swing` 결과와 교차. 둘 다 잡힌 종목만 주문표대로 진행
- 조건식 저장 후 **서버 저장**을 켜면 M-STOCK(MTS) MY전략에서도 같은 결과를 볼 수 있음

## 4. [0545] 실시간종목검색 — 데이트레이딩 (장중)

조건식 이름: `눌림목_데이`. 재검색 주기 **1분**, 감시 시간 **09:10~14:30**. 신호가 뜨면 `pullback plan --mode day --code 종목코드` 로 사다리 계산.

| 조건 | 분류(예상) | 항목 | 설정값 |
|---|---|---|---|
| A | 범위지정 | 시가총액 | **1,000억 이상** |
| B | 범위지정 | 20일 평균 거래대금 | **100억 이상** (`universe.day_min_avg_turnover`) |
| C | 시세분석 | 당일 거래대금 | **20억 이상** (`universe.day_min_intraday_turnover`) |
| D | 범위지정 | 현재가 | **1,000원 이상**, 관리·경고·정지 제외, 보통주만 |
| E | 시세분석 | 시가 갭 | **시가 ≤ 전일 종가 × (1 + 15%)** |
| F | 시세분석 | 당일 저가 대비 고가 | **(당일 고가 − 당일 저가) / 당일 저가 ≥ 3%** (임펄스) |
| G | 시세분석 | 당일 고가 대비 현재가 | **−1% ~ −7%** (눌림) |
| H | 기술적분석 | VWAP | **현재가 ≥ VWAP** (`require_above_vwap`) |
| I | 기술적분석 (3분봉) | 이동평균 | **현재가 ≥ 3분봉 MA20 × (1 − 1%)** |
| J | 거래량 (3분봉) | 거래량 수축 | **최근 3봉 평균 거래량 < 당일 평균 봉 거래량 × 0.8** |
| K | 패턴 (3분봉) | 반등 확인봉 | **직전 완료봉 양봉 AND 종가 > 그 전 봉 고가 AND 거래량 ≥ 그 전 봉 × 1.2** |
| L | 시세분석 | 상한가 근접 제외 | **현재가 ≤ 상한가 × 0.97** |

- 필터설정 창: 등락률 **+1% ~ +25%**, 거래대금 상위 정렬. 조건 중 F·G·K 는 HTS 항목이 없을 수 있음 → 그 경우 A~E, H 만 HTS 에서 걸고 F~K 는 프로그램(`pullback live --mode day`)이 판정

## 5. [0635] 서버 자동주문 — 종목마다 체결 직후 등록

주문표(`output/orders_*.md`) 의 손절가·목표가를 그대로 입력합니다. 분할 비중 **4:3:2:1** = 40% / 30% / 20% / 10%.

| 템플릿 | 감시 조건 | 주문 | 수량 | 유효기간 | 비고 |
|---|---|---|---|---|---|
| 손절 | 현재가 **≤ 손절가** | 매도 **시장가** (또는 지정가 −2틱) | **보유수량 전량** | 스윙: 기간(보유 종료까지) / 데이: 당일 | 발동 즉시 미체결 매수 사다리 **수동 취소** |
| 1차 목표 | 현재가 **≥ 1차목표** | 매도 지정가(1차목표) 또는 시장가 | **보유수량의 50%** | 동일 | 체결 후 미체결 사다리 취소, 손절 감시가를 **평단**으로 수정 (`move_stop_to_breakeven_after_t1`) |
| 2차 목표 | 현재가 **≥ 2차목표** | 매도 지정가(2차목표) | **잔량 전량** | 동일 | |
| 시간 청산(데이) | 시각 **15:15** | 매도 시장가 | 보유수량 전량 | 당일 | 예약주문/시간조건 지원 시. 없으면 알람 맞춰 수동 |
| 시간 청산(스윙) | 보유 **10거래일** 경과 | 종가 매도 | 전량 | — | 수동 (캘린더 알림) |

감시 시작/종료 시간: **09:00:30 ~ 15:19** (장마감 동시호가 전). 스탑 감시가는 호가단위에 맞춰 입력 (프로그램이 이미 맞춰 둠).
