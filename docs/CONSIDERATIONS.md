# 추가로 참고해야 할 사항 — 국내주식 눌림목 분할매수 단타/스윙

요구하신 조건(데이트레이딩+스윙, 눌림목 진입, 1:2:3:4 분할매수, 시가총액 100억 이상, 미래에셋 HTS)을 그대로 구현하면서,
실매매 전에 반드시 확인·결정해야 할 사항을 조사 결과와 함께 정리했습니다. 조사 시점은 2026년 10월입니다.

## 1. 미래에셋증권에는 개인용 자동매매 API 가 없다

- 2026년 10월 현재 미래에셋증권은 개인 고객 대상 Open API(REST/OCX)를 공식 제공하지 않습니다. 오픈 API 를 도입한 증권사 목록(한국투자증권, 키움, LS, 대신, NH, KB, 다올, 토스 등)에 미래에셋은 없습니다. ([시사저널e](https://www.sisajournal-e.com/news/articleView.html?idxno=422947), [클리앙 토론](https://www.clien.net/service/board/cm_stock/18535784))
- 따라서 **프로그램이 미래에셋 계좌에 주문을 직접 넣을 수 없습니다.** 선택지는 세 가지입니다.
  1. **주문표 방식(기본)** — 프로그램이 종목·사다리·손절·목표를 계산 → 카이로스 HTS 에 수동/예약 입력. 카이로스의 [0635] 서버 자동주문(스탑로스·목표가), [0545] 실시간종목검색을 함께 쓰면 반자동이 됩니다. ([카이로스 활용 가이드 PDF](https://securities.miraeasset.com/bbs/download/2047393.pdf?attachmentId=2047393), [0545 실시간종목검색](https://securities.miraeasset.com/kairos/0545.htm))
  2. **한국투자증권 계좌 추가** — KIS Developers REST API 로 완전 자동화. 본 프로그램에 어댑터 포함. ([KIS Developers](https://apiportal.koreainvestment.com/intro), [공식 GitHub](https://github.com/koreainvestment/open-trading-api))
  3. 키움 REST API, LS xingAPI 등 — 구조상 `execution/` 에 어댑터만 추가하면 됩니다.
- HTS 화면 자동 클릭(매크로) 방식은 약관 위반·오작동 위험이 커서 권하지 않습니다.

## 2. 거래비용 — 단타는 비용 싸움

| 항목 | 2026년 기준 | 비고 |
|---|---|---|
| 증권거래세+농특세 (매도 시) | 코스피 0.20% (거래세 0.05 + 농특세 0.15), 코스닥 0.20% | 2026-01-01 양도분부터 인상 ([머니투데이](https://www.mt.co.kr/economy/2025/12/01/2025120108471236062), [공공뉴스](http://www.00news.co.kr/news/articleView.html?idxno=100604)) |
| 위탁수수료 | 증권사·계좌별. 미래에셋 다이렉트 계좌 우대 시 유관기관 제비용 수준(≈0.0036%), 일반 온라인은 0.01~0.015% 안팎 | 본인 계좌의 실제 요율을 `cost.commission_pct` 에 넣을 것 |
| 스프레드 | 호가단위 1틱 (예: 10,000원 종목 10원 = 0.1%) | 저가주·호가 두꺼운 종목일수록 비율 큼 |
| 금투세 | 폐지. 국내 상장주식 양도차익 비과세(대주주 제외) | |

→ 왕복 비용 ≈ **0.23% + 1틱**. 10,000원 종목이면 손익분기 상승률 약 0.33%. 데이트레이딩 목표 수익이 이보다 2~3배는 커야 기대값이 양수가 됩니다. 프로그램은 1차 목표 수익률이 손익분기의 2배 미만이면 경고를 띄웁니다. `pullback costs` 로 바로 계산할 수 있습니다.

## 3. 시장 구조 — 알고 있어야 하는 규칙

- **거래시간**: KRX 정규장 09:00~15:30, 장전 동시호가 08:30~09:00, 장마감 동시호가 15:20~15:30, 장후 시간외 종가 15:40~16:00, 시간외 단일가 16:00~18:00. **NXT(넥스트레이드)** 프리마켓 08:00~08:50, 메인 09:00:30~15:20, 애프터마켓 15:40~20:00 (지정가만, KRX 시가·종가 결정 구간 휴장). ([넥스트레이드](https://nextrade.co.kr/main.do), [신한 해설](https://www.shinhangroup.com/kr/archive/insight/extend/detail/32955))
  - 데이트레이딩 강제청산은 15:20 동시호가 전(기본 15:15)에 끝내야 합니다.
  - NXT 애프터마켓 가격은 KRX 종가와 다를 수 있어 스윙 손절 판단은 KRX 정규장 종가 기준으로 하세요.
- **가격제한폭** ±30%. 신규상장 종목은 상장 첫날 공모가의 60~400% 로 다르므로 제외 대상입니다.
- **호가단위** (2023-01-25 개편, 코스피·코스닥 공통): 2천 미만 1원 / 2천~5천 5원 / 5천~2만 10원 / 2만~5만 50원 / 5만~20만 100원 / 20만~50만 500원 / 50만 이상 1,000원. 주문가는 반드시 호가단위에 맞춰야 하며 프로그램이 자동 보정합니다. ([한국거래소 개편 보도](https://news.mtn.co.kr/news-detail/2022110114103274390))
- **VI(변동성완화장치)**: 동적 VI 는 직전 체결가 대비 코스피200 ±3%, 코스피 일반·코스닥 ±6% (장마감 전 ±2/4%), 정적 VI 는 기준가 대비 ±10% 급등락 시 2분 단일가. 눌림목에서 급반등 시 VI 가 걸리면 사다리 체결가·손절 타이밍이 어긋납니다. 발동 직후 추격하지 말고 단일가 해제 후 판단하세요. ([KB 해설](https://kbthink.com/investment/101/vi.html))
- **결제 T+2** 지만 당일 매수분은 당일 매도 가능(데이트레이딩 가능). 매도대금은 당일 재매수에 쓸 수 있습니다.
- **증거금·미수**: 증거금률 100% 로 설정하지 않으면 현금보다 큰 주문이 들어가고(미수), 결제일까지 못 채우면 반대매매됩니다. 단타 계좌는 **증거금 100%** 가 안전합니다. 투자경고·위험 종목은 증거금 100%·신용 불가가 강제됩니다. ([KB 시장경보 해설](https://kbthink.com/stock/market-warning.html))

## 4. 종목 제외 기준 (시가총액 100억보다 중요한 것)

- **시가총액 100억 원 이상 조건은 사실상 아무것도 거르지 못합니다.** 코스닥 최하위권이 대략 100~300억 수준이라 상장사 거의 전부가 통과합니다. 프로그램은 요구대로 `min_market_cap: 100억` 을 두되, 실질 필터로 다음을 기본 적용합니다.
  - **20일 평균 거래대금 ≥ 30억 원** (`min_avg_turnover`). 사다리 4차까지 수백만 원씩 넣고 15:15 에 시장가로 나오려면 유동성이 필요합니다. 계좌가 크면 50~100억으로 올리세요.
  - **주가 ≥ 1,000원** (동전주 제외: 1원 호가 구간은 스프레드·조작 위험 큼)
  - **상장 60거래일 미만 제외**
  - 시총을 올리고 싶다면 300~500억 이상이 소형주 급등락·거래정지 리스크를 줄이는 현실적 선입니다.
- **종목 유형 제외**: 스팩, 우선주, ETF/ETN, 리츠, 인프라펀드 — 눌림목 매매 대상이 아니고 유동성이 낮습니다(이름 패턴으로 자동 제외).
- **상태 제외**: 관리종목, 투자주의/경고/위험(위험은 단일가매매), 거래정지, 정리매매, 불성실공시. KIS 시세 API 는 이 플래그를 주고, 다른 공급자는 카이로스 [0544] 검색 결과를 `config/exclusions.csv` 로 넣어야 합니다.
- **당일 상한가·상한가 근접 종목** 은 눌림목이 아니라 추격입니다. 감지기는 "직전 고점 대비 3% 이상 눌림" 을 요구하므로 자동으로 걸러집니다.
- 스윙 보유 중 **공시 리스크**: 유상증자·전환사채·감자·거래정지·실적발표·배당락/권리락. 보유 전 DART/HTS 공시를 확인하고, 실적발표일에 걸치는 포지션은 비중을 줄이세요.

## 5. 1:2:3:4 분할매수의 구조적 리스크

1:2:3:4 는 **내려갈수록 더 많이 사는 역피라미드(물타기형)** 입니다. 눌림목 매매와 궁합이 맞는 대신 다음을 알고 써야 합니다.
- **4차까지 체결됐다는 것은 눌림이 예상보다 깊어졌다는 신호** 입니다. 전체 수량의 70% 가 3·4차에 몰려 있으므로 손절 시 손실의 대부분이 여기서 납니다. 그래서 프로그램은 **"4차까지 전부 체결된 뒤 손절" 을 기준으로 수량을 정합니다** (계좌의 1%). 1차만 체결된 뒤 상승하면 수익은 작지만 손실도 작습니다.
- 4차가는 눌림 저점 바로 위, 손절가는 저점 아래에 둡니다. 저점을 깨면 셋업 자체가 무효이므로 "한 번 더 물타기" 는 없습니다. **5차는 없습니다.**
- **1차 목표 도달 시 미체결 사다리를 취소**해야 합니다. 안 그러면 상승 후 되돌림에서 2~4차가 체결되어 포지션이 커집니다.
- 손절 체결 후 **미체결 사다리가 남아 있으면 다시 매수됩니다.** 손절과 사다리 취소는 한 세트입니다. (카이로스 서버 자동주문엔 "스탑 발동 시 다른 주문 취소" 가 없으니 수동 확인 필수)
- 갭하락은 손절가보다 훨씬 아래에서 체결됩니다. 스윙은 종목당 리스크 1% 를 넘길 수 있다는 전제로 포지션 수(기본 3개)를 제한하세요.
- 백테스트 리포트의 "체결차수별 승률" 로 1:2:3:4 가 실제로 1:1:1:1 이나 4:3:2:1 보다 나은지 꼭 비교하세요. `ladder.weights` 만 바꾸면 됩니다.

## 7. 눌림목 정의를 숫자로 고정해야 한다

"눌림목" 은 사람마다 다릅니다. 프로그램은 다음 6조건으로 고정했고 전부 설정값입니다 (README §5). 핵심은
(1) 상승 추세 유지, (2) 명확한 상승파동 뒤 (3) 얕은 조정(되돌림 23.6~61.8%), (4) 조정 중 거래량 감소, (5) 이평/VWAP 지지, (6) 반등 확인봉.
([눌림목 매매 해설](https://f-daily.co.kr/%EC%A6%9D%EA%B6%8C/%EB%88%8C%EB%A6%BC%EB%AA%A9-%EB%A7%A4%EB%A7%A4-%EB%B0%A9%EB%B2%95/))
- `confirm`(확인봉 후 진입) 은 체결은 늦지만 거짓 눌림(추세 붕괴)을 거릅니다. `anticipate`(지지선 예약매수) 는 평단이 좋지만 하락 중 잡힐 위험이 큽니다. 먼저 `confirm` 으로 시작하세요.
- 데이트레이딩은 09:00~09:10 시초가 변동 구간과 14:30 이후를 피하고, VWAP 위에서만 매수합니다.

## 8. 데이터·실행 환경

- **pykrx** 는 KRX 정보데이터시스템이 로그인을 요구하면서 일부 함수에 `KRX_ID`/`KRX_PW` 가 필요해졌고, 과도한 호출은 차단됩니다. ([pykrx](https://github.com/sharebook-kr/pykrx))
- **네이버 금융 비공식 API** 는 로그인 없이 일봉·1분봉·시총 목록을 주지만 공식 지원이 아닙니다.
- **한국투자증권 API** 는 당일 분봉 30건/호출, 과거 분봉 120건/호출, 실전 20건/초 제한이 있습니다. 유니버스가 크면 폴링 주기를 늘리세요.
- 분봉 데이트레이딩 백테스트는 과거 분봉이 필요합니다. KIS 는 최대 1년, 네이버는 최근 며칠만 제공하므로 **매일 분봉을 캐시(`data/cache/minute/`)** 해 두는 습관이 필요합니다.

## 9. 백테스트를 믿기 전에

- 체결 가정이 결과를 좌우합니다. 본 엔진은 보수적(같은 봉에서 손절 우선, 사다리 체결 후 손절, 1틱 슬리피지)이지만 호가 잔량은 모릅니다.
- 유니버스 생존 편향: 상장폐지 종목이 빠진 데이터로 돌리면 성과가 부풀려집니다.
- 거래 수가 적으면(수십 건) 통계적 의미가 없습니다. 최소 수백 건, 여러 구간(상승장·하락장)에서 확인하세요.
- 파라미터를 백테스트에 맞춰 조정하면 과최적화됩니다. 기본값으로 먼저 돌려보고, 바꾸는 값은 한두 개로 제한하세요.
