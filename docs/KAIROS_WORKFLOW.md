# 미래에셋증권 카이로스(KAIROS) HTS 연동 워크플로우

미래에셋증권은 **개인 고객용 Open API(REST/OCX)를 제공하지 않습니다**(2026년 10월 기준 공식 안내 없음, 커뮤니티 확인).
따라서 이 프로그램은 미래에셋 계좌에 **직접 주문을 넣지 못하며**, 다음 두 가지 방식으로 씁니다.

| 방식 | 설명 | 설정 |
|---|---|---|
| A. 주문표 + 카이로스 수동/예약 주문 | 프로그램이 종목·사다리 가격·수량·손절·목표를 계산해 주문표(MD/CSV)로 출력 → 카이로스에서 입력 | `broker.mode: sheet` |
| B. 한국투자증권 계좌로 자동주문 | KIS Developers REST API 로 사다리/손절/목표를 자동 집행 (추가 계좌 개설 필요) | `broker.mode: kis` ([KIS_SETUP.md](KIS_SETUP.md)) |

카이로스 안에도 자동화 도구가 있습니다. 프로그램이 낸 숫자를 아래 화면에 그대로 입력하면 장중에 붙어 있지 않아도 손절·목표 청산이 실행됩니다.

- **[0544] 종합종목검색 / [0545] 실시간종목검색** — 조건식 저장, 실시간 감시, 주기 재검색. 프로그램 스캔 결과와 교차 확인용.
- **[0635] 서버 자동주문 / [0636] 신청·해지** — 서버에서 감시하는 조건부 주문(스탑로스, 트레일링, 목표가). HTS 를 꺼도 유지.
- **신호 모니터링** — 스탑로스·시세감시·조건검색 신호를 한 화면에서 확인.
- **시스템 트레이딩(전략센터)** — 차트 수식 기반 전략 작성·백테스트. 눌림목 조건식을 여기에도 옮길 수 있음.

(화면번호는 미래에셋증권 카이로스 매핑표 기준이며 버전에 따라 다를 수 있습니다. HTS 상단 화면검색창에 화면명을 입력하면 찾을 수 있습니다.)

## 1. 스윙 매매 일일 루틴 (일봉)

1. **장 마감 후(15:40 이후) 스캔**
   ```bash
   pullback scan --mode swing --provider naver          # 또는 pykrx / fdr / csv
   ```
   - `output/orders_YYYYMMDD_swing.md` (사람용), `.csv` (입력용) 생성
   - 각 종목: 1~4차 매수가/수량, 손절가, 1차·2차 목표가, 유효기간(기본 3거래일), 리스크 금액
2. **카이로스 교차 확인** — [0544] 조건검색에서 아래 조건으로 검색해 프로그램 결과와 겹치는 종목을 우선
   - 종가 > 20일 이평 > 60일 이평
   - 20일 내 최고가 대비 −3% ~ −20% 구간
   - 최근 5일 거래량 평균 < 직전 10일 거래량 평균 (거래량 감소)
   - 관리종목·투자경고·거래정지 제외, 시가총액 ≥ 1,000억, 20일 평균 거래대금 ≥ 50억
   - 조건식 전체 세팅값은 [KAIROS_SETTINGS.md](KAIROS_SETTINGS.md) (또는 `pullback hts --mode swing`)
3. **주문 입력 (다음 날 장 시작 전, 08:30 전후)**
   - 1~4차 **매수 지정가 4건** 입력 (주문표의 가격·수량 그대로). 유효기간이 여러 날이면 *예약주문* 으로 걸어 두거나 매일 아침 재입력
   - **[0635] 서버 자동주문** 에 손절 조건 등록: `현재가 ≤ 손절가 → 보유수량 전량 시장가 매도`
   - 1차 목표: `현재가 ≥ 1차목표 → 보유수량의 50% 지정가(또는 시장가) 매도`, 2차 목표: 잔량
4. **장중 규칙** (주문표 하단 '규칙' 그대로)
   - 손절가 이탈 → 전량 매도 + 미체결 사다리 전부 취소 (사다리가 남아 있으면 손절 후 다시 사게 됨!)
   - 1차 목표 도달 → 50% 청산, **남은 미체결 사다리 취소**, 손절가를 평단으로 상향
   - 유효기간 지난 사다리 취소
   - 최대 보유 10거래일 경과 시 종가 청산
5. **매매일지** — `output/` 의 주문표와 실제 체결을 대조해 기록. 백테스트 가정(체결가·슬리피지)과의 차이를 추적

## 2. 데이트레이딩 루틴 (분봉)

데이트레이딩은 분봉이 필요합니다. 네이버(비공식, 1분봉) 또는 한국투자증권 시세 API 를 쓰고, 주문은 카이로스에서 수동으로 넣는 구성이 현실적입니다.

```bash
pullback live --mode day --broker sheet --provider naver --poll 60
```

- 09:10~14:30 사이 60초마다 유니버스를 스캔, 눌림목 확인봉이 나오면 **알림 + 주문표 갱신**
- 텔레그램 봇 토큰을 설정하면 휴대폰으로 알림 (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`)
- 1차(40%)는 확인봉 직후 시장가(기본값), 2~4차(30/20/10%)는 눌림 저점까지 균등 지정가, 손절은 저점 −0.5%
- 실시간종목검색 조건식과 서버 자동주문 템플릿은 [KAIROS_SETTINGS.md](KAIROS_SETTINGS.md) (`pullback hts --mode day`)
- **15:15 강제청산** — 장마감 동시호가(15:20~15:30) 에 걸리지 않도록 그 전에 전량 정리. 당일 매수분은 당일 매도 가능(결제는 T+2)
- 카이로스 **[0635] 서버 자동주문** 의 스탑로스를 매수 체결 직후 바로 등록하는 습관이 가장 중요

## 3. 카이로스 계좌·주문 설정 체크리스트

- 증거금률 **100%** 로 설정 (미수 발생 → 반대매매 위험 제거). 투자경고 종목은 어차피 100%·신용 불가
- 주문 확인창 켜 두기 (수량 오입력 방지), 시장가 주문은 유동성 상위 종목에만
- 장전 동시호가(08:30~09:00)·장마감 동시호가(15:20~15:30) 에는 체결가가 예측 불가 → 사다리 지정가만 사용
- NXT(넥스트레이드) 프리/애프터마켓 체결 여부는 계좌 설정에 따름. 애프터마켓 가격은 KRX 종가와 다를 수 있으니 스윙 손절 기준은 KRX 정규장 종가로
- VI(변동성완화장치) 발동 종목은 2분 단일가 — 발동 직후 추격 금지. 프로그램 `market/vi.py` 로 주문가가 VI 를 유발하는지 확인 가능

## 4. 데이터 내보내기 (CSV 공급자)

네이버/KRX 접근이 막힌 환경이면 카이로스 차트에서 일봉/분봉을 엑셀로 내보내 `data/csv/` 에 넣고 `provider: csv` 로 돌릴 수 있습니다.

```
data/csv/universe.csv                  code,name,market,market_cap,close,turnover
data/csv/daily/005930.csv              일자,시가,고가,저가,종가,거래량[,거래대금]
data/csv/minute/005930_20261012.csv    일시,시가,고가,저가,종가,거래량
```
한글/영문 헤더 모두 인식하며 날짜는 `20261012`, `2026-10-12`, `2026/10/12 09:03` 형식을 받습니다.
